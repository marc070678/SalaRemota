# Requisitos Funcionais

RF-001 Autenticar professor.
RF-002 Encerrar sessão do professor.
RF-003 Criar sala.
RF-004 Gerar convite/código temporário.
RF-005 Solicitar entrada do aluno.
RF-006 Aceitar ou recusar aluno.
RF-007 Encerrar sala.
RF-008 Compartilhar tela do professor.
RF-009 Parar compartilhamento do professor.
RF-010 Compartilhar tela do aluno mediante ação do aluno.
RF-011 Parar compartilhamento do aluno.
RF-012 Exibir tela compartilhada do participante remoto.
RF-013 Habilitar áudio bidirecional.
RF-014 Enviar arquivo permitido.
RF-015 Receber arquivo permitido.
RF-016 Iniciar e parar gravação com indicação visual.
RF-017 Solicitar controle remoto.
RF-018 Autorizar ou recusar controle remoto.
RF-019 Revogar controle remoto localmente.
RF-020 Registrar eventos críticos de segurança e sessão.
