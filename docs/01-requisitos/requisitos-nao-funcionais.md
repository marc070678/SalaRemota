# Requisitos Não Funcionais

RNF-001 Segurança por padrão.
RNF-002 Privacidade por concepção.
RNF-003 Comunicação externa criptografada em produção.
RNF-004 Nenhum segredo em repositório.
RNF-005 Logs sem credenciais, tokens completos ou conteúdo sensível desnecessário.
RNF-006 Tratamento global de erro sem exposição de detalhes internos.
RNF-007 Arquitetura testável e modular.
RNF-008 Domínio independente de UI, banco e fornecedor de WebRTC.
RNF-009 Auditoria com correlation id quando aplicável.
RNF-010 Dependências de terceiros devem ser justificadas e avaliadas.
RNF-011 O aluno deve conseguir interromper recursos sensíveis localmente.
RNF-012 O sistema deve suportar evolução de 1:1 para 1:N sem remodelagem destrutiva do domínio de sala.
