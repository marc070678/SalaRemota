# Security Checklist

- [ ] Entrada validada no servidor.
- [ ] Autenticação aplicada quando necessária.
- [ ] Autorização aplicada por recurso/ação.
- [ ] Tokens possuem expiração e escopo mínimo.
- [ ] Segredos não estão em código/config versionada.
- [ ] Logs não contêm segredos ou dados sensíveis desnecessários.
- [ ] Erros não expõem stack trace ou infraestrutura.
- [ ] Rate limit considerado.
- [ ] Testes negativos/de abuso adicionados.
- [ ] Threat model revisado.
- [ ] Dados pessoais minimizados.
- [ ] Retenção documentada.
- [ ] Dependências novas justificadas.
