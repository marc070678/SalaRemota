# Inventário Inicial de Dados — LGPD

## Professor

- Nome: necessário para identificação operacional.
- Email: autenticação/contato de conta.
- PasswordHash: autenticação; nunca senha original.
- Status da conta.
- Timestamps técnicos.

## Participante aluno no MVP

- DisplayName.
- Identificador técnico de sessão/participação.
- Timestamps necessários.

## Dados que não serão coletados no MVP sem nova justificativa

- CPF/RG.
- Endereço residencial.
- Biometria.
- Data completa de nascimento.
- Dados de saúde.
- Fotografias permanentes.

## Dados transitórios/sensíveis no contexto da aula

Tela, áudio, materiais e gravação devem ser tratados conforme finalidade explícita e com retenção mínima.
