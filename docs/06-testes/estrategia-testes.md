# Estratégia de Testes

Camadas:

- Unitários: domínio e aplicação.
- Integração: banco, autenticação, autorização, APIs.
- E2E: fluxos críticos professor/aluno.
- Segurança: testes negativos, abuso, autorização e sessão.
- Arquitetura: dependências entre projetos.

Cada funcionalidade deve possuir happy path e cenários de negação/erro relevantes.
