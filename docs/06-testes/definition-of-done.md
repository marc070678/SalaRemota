# Definition of Done

Uma tarefa somente está concluída quando:

- [ ] Compila sem erros.
- [ ] Testes existentes continuam passando.
- [ ] Novos testes relevantes foram adicionados.
- [ ] Entradas são validadas.
- [ ] Autorização foi revisada.
- [ ] Erros são tratados de forma segura.
- [ ] Nenhum segredo foi versionado.
- [ ] Logs foram revisados.
- [ ] Documentação foi atualizada.
- [ ] Security checklist aplicável foi revisado.
- [ ] Critérios de aceite foram atendidos.
- [ ] Nenhum recurso fora do escopo foi implementado sem decisão registrada.
